# termaxa Homebrew tap

```bash
brew install termaxa/tap/termaxa
```

Installs the prebuilt binary from [GitHub Releases](https://github.com/termaxa/termaxa/releases),
pinned by sha256. Formula is CI-tested on macOS and Linux on every change.

Termaxa is a cooperative gate for the shell commands AI coding agents run —
command previews, automatic backups, allow/ask/deny policy, audit logging.
Docs and threat model: https://github.com/termaxa/termaxa
